Semester start game jam project

<!--more-->

Time: 4 days  
Team: 6 people, 3 from game dev, 3 from game graphics  
Engine: Unity  
Theme: Horror  

This was a game jam project to jump start the semester with. From the horror theme we decided on making a desktop-based game where you download a desktop pet virus that eventually takes over your personal blog site and eventually the entire computer.  
Because this game ended up being so asset and text heavy, I worked on design, UI assets and writing rather than much programming. Using the graphics team's inspiration board for late 90's to early 2000's aesthetic, we found a fun color palette and I used it to riff on the Windows XP UI design. the program icons are "silly" versions of the Microsoft Edge broswer and MSN Messenger icons. The desktop pet slowly devolves as you play to slowly reveal that it is in fact not your friend, by having it start as a round and friendly-looking dolhpin, and "transforming" into a sharp-angled and almost gross looking goblin shark.  
Since it was such a short project we didn't have time to implement everything quite how I had planned, but I'm still satisfied with it as a game jam project.
